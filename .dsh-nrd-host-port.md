# NRD host-shader port recipe (exact, from NRD v4.17.3)

Source: `Shaders/NRD.hlsli` @ tag v4.17.3, plus `CMakeLists.txt` option defaults.
These are the helpers the host must port to Slang. Guessing any of them produces a wrong image, so they
are recorded verbatim here as the porting reference.

## Constants

```
#define NRD_FP16_MAX 65504.0
#define NRD_EPS      1e-6      // must fit into FP16
```

## Build-time encoding defaults (CMakeLists.txt:28-29, written into NRDConfig.hlsli:75-85)

```
NRD_NORMAL_ENCODING    = 2   // R10G10B10A2_UNORM
NRD_ROUGHNESS_ENCODING = 1   // SQRT_LINEAR  -> roughness stored as sqrt(linear)
```
Consequences for the host:
- The `IN_NORMAL_ROUGHNESS` texture must be created as `VK_FORMAT_A2B10G10R10_UNORM_PACK32`.
- Roughness must be written as `sqrt(linear roughness)`, not linear.
- NRD's C++ build and the host shaders must agree on these two values. The shim pins them; if either
  changes, both sides change together.

## Colour packing (NRD.hlsli:398-417)

```hlsl
float3 _NRD_LinearToYCoCg( float3 color ) {
    float Y  = dot( color, float3(  0.25, 0.5,  0.25 ) );
    float Co = dot( color, float3(  0.5,  0.0, -0.5  ) );
    float Cg = dot( color, float3( -0.25, 0.5, -0.25 ) );
    return float3( Y, Co, Cg );
}

float3 _NRD_YCoCgToLinear( float3 color ) {
    float t = color.x - color.z;
    float3 r;
    r.y = color.x + color.z;
    r.x = t + color.y;
    r.z = t - color.y;
    return max( r, 0.0 );
}
```

## Hit-distance normalization (NRD.hlsli:548-562, 774-782)

```hlsl
float _NRD_GetSpecMagicCurve( float roughness, float power ) {
    float f = 1.0 - exp2( -200.0 * roughness * roughness );
    f *= pow( saturate( roughness ), power );
    return f;
}

float _REBLUR_GetHitDistanceNormalization( float viewZ, float3 hitDistParams, float roughness ) {
    float smc = _NRD_GetSpecMagicCurve( roughness, 0.5 );
    return ( hitDistParams.x + abs( viewZ ) * hitDistParams.y ) * lerp( hitDistParams.z, 1.0, smc );
}

float REBLUR_FrontEnd_GetNormHitDist( float hitDist, float viewZ, float3 hitDistParams, float roughness ) {
    float f = _REBLUR_GetHitDistanceNormalization( viewZ, hitDistParams, roughness );
    hitDist = saturate( hitDist / f );
    // 0 would mean "no data" (lobe skipped by probabilistic selection), which is not the case here
    return max( hitDist, NRD_EPS );
}
```
`hitDistParams` is `ReblurSettings::hitDistanceParameters` (A, B, C) — the shim and the host shader must
use the same triple.

## Radiance + hit distance (NRD.hlsli:787-799, 842-847)

```hlsl
float4 REBLUR_FrontEnd_PackRadianceAndNormHitDist( float3 radiance, float normHitDist, bool sanitize ) {
    if( sanitize ) {
        radiance    = _NRD_IsInvalid( radiance ) ? float3(0,0,0) : clamp( radiance, 0, NRD_FP16_MAX );
        normHitDist = _NRD_IsInvalid( normHitDist ) ? 0 : saturate( normHitDist );
    }
    radiance = _NRD_LinearToYCoCg( radiance );
    return float4( radiance, normHitDist );
}

float4 REBLUR_BackEnd_UnpackRadianceAndNormHitDist( float4 data ) {
    data.xyz = _NRD_YCoCgToLinear( data.xyz );
    return data;
}
```
`_NRD_IsInvalid(x) = any(isnan(x)) || any(isinf(x))`.

REBLUR radiance inputs are also **demodulated** (README:809) and kept in [0;250]; the host decides what to
demodulate by, and must re-modulate the denoised output.

## Normal + roughness packing (NRD.hlsli:690-726)

Branches on the two encoding macros; with the defaults above only the R10G10B10A2_UNORM + SQRT_LINEAR path
matters. `materialID` is documented "Not used in NRD".

## What the host passes (per the integration report)

- `IN_MV` must be created with `VK_IMAGE_USAGE_STORAGE_BIT`: REBLUR's temporal-stabilization pass writes
  it in place. All NRD-bound textures need SAMPLED|STORAGE, 1 mip, 1 layer, 2D.
- NRD does **not** take albedo, specular albedo or specular motion vectors as inputs; those stay host-side.
- REBLUR_DIFFUSE_SPECULAR steady state is 7 dispatches per frame (8 with validation); frame 0 forces
  CLEAR_AND_RESTART and prepends roughly 24 clear dispatches, so size descriptor pools from
  `InstanceDesc::descriptorPoolDesc.setsMaxNum` (~46), not from the steady state.
